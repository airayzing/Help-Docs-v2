# 📖 Orders

### Orders Section - WhatsApp Catalogue

The **Orders** section displays all orders placed via the **WhatsApp Catalogue**, allowing for **efficient tracking and management**.

#### User Information

The orders section includes key customer details for easy identification:

* User Name
* Phone Number
* Email

These details help in tracking customer orders and facilitating communication.

#### Item Count

Each order displays the **quantity of items** purchased, helping businesses manage inventory and fulfillment efficiently.

#### Total Amount

The **Total** column shows the complete value of each order, allowing for **quick financial review** and tracking.

#### Tags

1. Assign tags to an order for **better organization** and categorization.
2. To create a new tag, click on the **"Create Tag"** button in the dropdown menu.

#### Order Status

1. Assign a **status** to each order to track its progress.
2. To create a new status, click on the **"Create Status"** button in the dropdown menu.

This section helps businesses manage and monitor WhatsApp Catalogue orders seamlessly, ensuring a **structured workflow**.
