
# Install Website Bot on WordPress

This page contains the tutorial on how to install the eleapi website bot on WordPress.

eleapi website bots support all sorts of websites. However, the most common of all is WordPress. Here is how you can integrate chatbots on WordPress websites.

## ✅ Installation Instructions

### 1. Get your bot ready to go-live
Before you move ahead, make sure you have completed the following steps:

- Create your bot on the eleapi dashboard.
- Design your chatflow and other design settings from the bot setup page.
- Once done, go to the eleapi setup page and then click on **Install your Chatbot**.
- Select WordPress and copy the API Code/Key. Save it safely.

### 2. Install the eleapi chat plugin from the WordPress plugin center
Once you have completed the first step, go to the WordPress site admin dashboard.

- Find the WordPress plugin center and search for **eleapi** in the search box.
- Once you find the eleapi Plugin, install it.
- Upon installation, you will see the **Activate** option. Click on the activate button to activate the plugin.

### 3. Paste API Code/key and make the bot live
Once the eleapi plugin is activated, look for **Tools** in the side menu.

- Under tools, you will find the **eleapi** option.
- Open the eleapi option, and you will see the option to paste the eleapi API code/key that you copied in the first step.
- Paste the API key/code and proceed by saving the key.

### 4. Test your bot now
You have completed all the heavy lifting. Open your website in private mode (Incognito window) to avoid any cache issues, and you will find the eleapi chatbot on your website.
