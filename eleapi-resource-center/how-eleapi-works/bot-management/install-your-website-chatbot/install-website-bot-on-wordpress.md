# Install Website Bot on WordPress

Eleapi's website bots support all sorts of websites. However, the most common of all is WordPress. Here is



## ✅ Installation Instructions

#### 1. Get your bot ready to go-live

Before you move ahead, make sure you have completed the following steps:

1. Create your bot on the Eleapi's dashboard.
2. Design your chatflow and other design settings from the bot setup page.
3. Once done, go to the Eleapi's setup page and then click on **Install your Chatbot**.
4. Select WordPress and copy the API Code/Key. Save it safely.

#### 2. Install the Eleapi's chat plugin from the WordPress plugin center

Once you have completed the first step, go to the WordPress site admin dashboard.

* Find the WordPress plugin center and search for Eleapi's in the search box.
* Once you find the Eleapi's Plugin, install it.
* Upon installation, you will see the **Activate** option. Click on the activate button to activate the plugin.

#### 3. Paste API Code/key and make the bot live

Once the Eleapi's plugin is activated, look for **Tools** in the side menu.

* Under tools, you will find the Eleapi's option.
* Open the Eleapi's option, and you will see the option to paste the Eleapi's API code/key that you copied in the first step.
* Paste the API key/code and proceed by saving the key.

#### 4. Test your bot now

You have completed all the heavy lifting. Open your website in private mode (Incognito window) to avoid any cache issues, and you will find the Eleapi's chatbot on your website.
